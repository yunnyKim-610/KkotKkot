처음 쓰는 방법
  1. 단독 펌웨어를 올린다:
    idf.py -B build-solo -D SDKCONFIG=build-solo/sdkconfig -D "SDKCONFIG_DEFAULTS=sdkconfig.defaults;sdkconfig.solo" -p COM5 flash
  2. 다른 프로그램(idf.py monitor 등)이 COM 포트를 쓰고 있으면 닫는다.
  3. 저장소 루트에서 python -m http.server 8000 실행 후 이 페이지를 연다.
  4. 「보드 연결」 → ESP32-S3 포트(USB JTAG/serial) 선택 → 「보드 리셋」으로 부팅 로그 확인. 부팅 시 LED가 0.3초 초록으로 켜진다.
  5. 「1단계」「2단계」를 눌러 보드 LED가 노랑·빨강으로 켜지는지 본다. 안 켜지면 LED 핀(KKOT_STATUS_LED_GPIO, 48 또는 38)을 확인한다.
