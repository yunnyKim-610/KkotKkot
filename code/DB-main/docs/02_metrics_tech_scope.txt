꼿꼿 AI 성공 지표, 기술 스택, 개발 범위

1. 모델 성능 지표
자세 유형(허리 구부림, 목 숙임, 어깨 웅크림) 분류 F1-score는 80% 이상을 목표로 하며, 현장에서 촬영한 라벨 데이터셋(약 5,000개 클립)으로 검증합니다. 박스나 장비에 신체 일부가 가려지는 상황(가려짐 비율 30% 이상 클립)에서도 F1-score 70% 이상을 유지해야 합니다.

정상 자세에 알림이 발생하는 오탐률은 10% 이하, 흐트러진 자세를 놓치는 미탐률은 20% 이하가 목표입니다. 테스트 기간의 라벨 비교와 근로자 피드백으로 측정합니다.

2. 시스템 성능 지표
Edge 디바이스(Jetson 기준)에서는 TensorRT 변환 후 구역당 최대 5인을 15 FPS 이상으로 처리합니다. 자세 판정부터 경광등 점등까지의 알림 지연은 2초 이내입니다. 시스템 가동률은 교대 시간 기준 99% 이상이며 헬스체크 로그로 측정합니다.

3. 행동 지표
알림 발생 후 30초 이내에 자세를 교정하는 비율 60% 이상을 목표로 하며, 알림 로그와 교정 이벤트 로그로 측정합니다. 구역당 일일 흐트러진 자세 누적 시간은 도입 전 2주 평균 대비 도입 4주 후 30% 감소를 목표로 하며 주간 집계로 확인합니다.

4. 사용성 지표
알림 피로를 막기 위해 근로자 1인당 교대당 알림 횟수를 8회 이하로 제한합니다. 알림 기능을 켜둔 채 7일 연속 사용하는 비율은 90% 이상이 목표입니다. 근로자 수용도는 도입 4주차 설문(5점 척도)에서 3.5점 이상이어야 합니다.

5. 프라이버시 및 컴플라이언스 지표
"감시받는 느낌"을 묻는 4주차 설문(5점 척도)에서 2.5점 이하를 유지합니다. 사전 설명회 이후 근로자의 옵트인 동의율은 90% 이상이어야 합니다. 영상 및 얼굴 데이터의 저장 건수는 0건이며, 저장소 감사 로그로 정기 점검합니다.

6. 기술 스택: 영상이 현장 밖으로 나가지 않는 구성
카메라·센서: 1080p PoE IP 카메라(광각 FOV 약 100°, RTSP)를 씁니다. 전원·영상 케이블 1선으로 설치가 단순하고 물류센터 천장 설치에 표준적입니다. 작업 구역 1개소당 조도 센서 1개를 두어 조명 변화 시 영상 보정과 인식률 저하 구간을 표시합니다.

Edge AI: NVIDIA Jetson Orin Nano 8GB(JetPack, TensorRT)를 씁니다. 구역 단위 실시간 추론이 가능하고, 영상이 현장 밖으로 나가지 않는 온디바이스 처리에 적합합니다.

AI 모델: YOLOv8-Pose(n/s)와 ByteTrack을 주력 후보로, MediaPipe Pose를 비교군으로 둡니다. 다중 인원 동시 추정에 강한 YOLOv8-Pose를 우선 검토하고, PoC에서 두 모델을 비교해 확정합니다. Ultralytics YOLOv8은 AGPL-3.0이라 상용 제품에는 엔터프라이즈 라이선스 검토가 필요하고, MediaPipe(Apache 2.0)는 상대적으로 부담이 적습니다.

자세 판정 로직: Python, NumPy, OpenCV와 타이머 기반 상태머신으로 구현합니다. 각도·거리 계산과 지속시간 판정은 규칙 기반이 설명 가능하고 임계값 조정이 쉽습니다. 2단계에서 경량 시계열 분류기(1D-CNN) 도입을 검토합니다.

제어·통신: ESP32-S3로 경광등·부저 릴레이를 제어합니다. Edge와 제어기 사이는 MQTT(Mosquitto), Edge와 서버 사이는 HTTPS/MQTT를 쓰며 사내 유선 LAN으로 연결합니다. 소음·간섭이 많은 현장에서는 유선이 안정적입니다.

서버·대시보드: 온프레미스 x86 서버 1대(Ubuntu, Docker)에서 통계 데이터만 수집합니다. 데이터베이스는 시계열 이벤트 집계와 보관 주기 관리가 쉬운 PostgreSQL + TimescaleDB, 대시보드는 Streamlit(MVP)이며 이후 Grafana를 검토합니다.

알림 시스템: 1차는 현장 경광등+부저, 2차는 관리자 메신저/이메일 일일 요약입니다. 소음이 큰 현장에서는 소리만으로 부족해 시각 알림을 병행하며, 관리자 알림은 익명 집계만 전송합니다.

7. 개발 범위
실시간 신체 키포인트 추정(다중 인원, 임시 ID 추적), 자세 각도 계산과 3유형 분류, 지속시간 기반 판정 및 휴식·이동 구간 자동 일시정지, 경광등·부저 제어(ESP32, MQTT)와 교정 확인, 이벤트 로그 저장(키포인트·집계값만 저장), 관리자 대시보드, 구역 ROI 설정과 교대 시작 시 기준 자세 측정, 장치 헬스체크와 장애 알림, 현장 데이터 수집·라벨링 및 모델 성능 검증이 포함됩니다.

8. 개발 비범위
얼굴 인식·개인 신원 식별, 음성 인식, 영상 저장 및 외부 전송, 의학적 진단·치료 판단, 근로자 개인별 인사평가·징계 목적의 데이터 활용, 모바일 앱, 다국어 지원, 세분화된 사용자 권한, 클라우드 모델 학습 자동화(MLOps)는 개발하지 않습니다. 웨어러블 센서 연동·진동 알림과 중량물 인양 동작 분석은 MVP 이후에 검토합니다.
