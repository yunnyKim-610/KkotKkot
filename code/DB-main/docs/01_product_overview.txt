꼿꼿 AI 제품 소개와 사용자 시나리오

1. 제품 개요
꼿꼿 AI는 "바른 자세가 만드는 건강한 생산성"을 목표로 하는 자세 교정 피지컬 AI 제품입니다. 근로자가 아무것도 착용하지 않아도, 천장 카메라와 Edge AI가 물류 현장 근로자의 허리 구부림·목 숙임·어깨 웅크림을 감지해 경광등과 부저로 즉시 알려 줍니다. 카메라 영상은 15 FPS로 Edge 디바이스에서 처리되며, 현장 경광등·부저와 연동됩니다.

2. 꼿꼿 AI가 푸는 문제
물류 현장 근로자는 분류·피킹·상하차 작업에서 허리를 반복해서 구부리거나, 목을 숙인 채 장시간 서서 일하거나, 어깨를 웅크린 자세를 유지합니다. 이런 자세가 누적되면 허리·목·어깨의 근골격계 부담이 커질 수 있습니다.

3. 기존 방식의 한계
주기적 안전 교육과 스트레칭 방송은 실제 작업 중 자세를 실시간으로 교정해 주지 못합니다. 관리자의 현장 순회 점검은 시간이 많이 들고, 모든 근로자를 상시 관찰할 수 없습니다. 근로자 본인은 작업에 집중하느라 자기 자세가 나빠졌는지 인지하기 어렵습니다. 웨어러블 센서는 착용 거부감과 배터리 관리 부담이 큽니다.

4. 꼿꼿 AI의 핵심 가치
근로자에게는 아무것도 착용하지 않아도 작업 중 자세 이탈을 즉시 알려 줍니다. 관리자에게는 구역·시간대별 익명 통계를 제공해 작업대 높이, 동선 등 환경 개선의 근거를 줍니다.

5. 왜 AI가 필요한가
규칙 기반 영상 처리(배경 차분, 윤곽 분석)는 작업복, 안전조끼, 박스 가려짐, 다중 인원 환경에서 관절 위치를 안정적으로 찾지 못합니다. 딥러닝 기반 자세 추정(Pose Estimation)은 다양한 체형과 조명에서 관절 좌표를 추정할 수 있습니다. 이 좌표로 각도를 계산하고 지속시간을 판정하면 사람이 일일이 보지 않아도 같은 기준으로 판단할 수 있습니다.

6. 사용자 시나리오: 설치부터 교정까지 6단계
페르소나(가정)는 분류 작업대에서 하루 8시간 서서 일하는 40대 근로자 김 씨입니다.

1단계 제품 설치: 설치 담당자가 작업 구역 천장·기둥(높이 약 3m, 하향 30°, 작업자 측면 45° 방향)에 PoE 카메라와 Edge 디바이스를 고정하고, 작업대 옆에 경광등·부저 제어함을 설치합니다. 대시보드에서 구역별 ROI(감시 영역)를 지정하고 시험 촬영으로 키포인트 인식률을 확인합니다.

2단계 데이터 수집: 카메라가 15fps로 영상을 받아 Edge 디바이스에 전달합니다. 교대 시작 시 작업 구역에서 10초간 바른 자세를 측정해 해당 세션의 기준값을 잡습니다. 기준값은 얼굴 인식 없이 교대 단위 임시 ID로만 관리하며 교대 종료 시 폐기합니다.

3단계 AI 분석: Edge 디바이스가 프레임에서 사람을 검출하고 17개 관절 키포인트를 추정합니다. 추적기가 임시 ID를 부여하고, 허리 굽힘각·목 숙임각·어깨 높이차를 계산합니다. 원본 프레임은 메모리에서만 처리하고 즉시 폐기합니다.

4단계 판단 결과 생성: 각도가 임계값을 넘은 상태가 지속되면 "흐트러진 자세"로 판정하고 허리 구부림 / 목 숙임 / 어깨 웅크림으로 유형을 분류합니다. 순간적인 물건 집기 동작은 제외하고, 휴식·이동으로 판단되는 구간(보행 속도 이상, 관절 다수 미검출)은 자동 일시정지합니다.

5단계 장치 제어: 판정 조건이 충족되면 Edge가 MQTT로 해당 구역의 ESP32 제어기에 신호를 보내 경광등을 켜고 부저를 울립니다. 같은 근로자에게 알림은 교대당 최대 8회로 제한하고, 재알림은 최소 5분 간격을 둡니다.

6단계 후속 행동: 근로자가 알림을 보고 자세를 바로잡으면 시스템이 정상 자세 복귀를 감지해 경광등을 소등하고 "교정 성공"을 기록합니다. 안전관리자는 대시보드에서 구역별 익명 통계를 확인하고, 반복 발생 구역은 작업대 높이나 동선 개선에 반영합니다.

7. 자세 판정 기준 (초기값, 가정)
허리 구부림: 어깨-골반-무릎 기준 몸통 굽힘각이 30°를 초과한 상태가 10초 이상 지속될 때 판정합니다.
목 숙임: 귀-어깨 기준 목 전방 숙임각이 30°를 초과한 상태가 15초 이상 지속될 때 판정합니다.
어깨 웅크림: 좌우 어깨 높이차 또는 어깨-귀 거리 감소율이 기준값 대비 20% 이상인 상태가 20초 이상 지속될 때 판정합니다.
임계값은 REBA, ISO 11226 등 인간공학 평가 기준을 참고하되 산업보건 전문가 검토 후 확정합니다. 2D 영상은 카메라 각도에 따라 굽힘각 오차가 커지므로 측면 45° 설치를 권장합니다.

8. 제품 포지셔닝
꼿꼿 AI는 자세 인식 개선 보조 도구이며 질환 예방·치료·진단을 표방하지 않습니다. 영상과 얼굴 데이터는 저장하지 않고, 관리자에게는 익명 집계만 제공합니다.
