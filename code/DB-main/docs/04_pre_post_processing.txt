꼿꼿 AI 전처리 4단계와 후처리 6단계

1. 전처리 파이프라인 개요
현장 조사 결과를 근거로 영상 → 키포인트 → 시계열 → 학습 데이터 순서의 전처리 파이프라인을 설계했습니다. 조명·가림·떨림·개인차를 단계별로 걸러내 오알림 없이 정확하게 감지하는 것이 목적입니다. 아래 파라미터는 현장 조사 반영 전 일반 조건 기준의 초기값입니다.

2. A 영상 단계
A1 프레임 샘플링: 항상 적용하며, 30fps 입력이면 2~3프레임마다 1회씩 10~15fps로 추론합니다.
A2 렌즈 왜곡 보정: 광각·어안 렌즈일 때 체커보드 캘리브레이션 15~20장으로 보정 맵을 사전 계산합니다. 저사양 대안으로 영상 대신 키포인트 좌표에만 보정을 적용할 수 있습니다.
A3 영상 안정화: 이동형 거치 또는 진동이 있을 때 배경 특징점(ORB) 500개 기반 어파인 보정과 이동평균 반경 15프레임을 씁니다.
A4 조명 보정: 저조도·역광이면 평균 밝기 80 미만일 때 감마 0.6~0.8을 적용하고, 조명 변화에는 LAB의 L 채널에만 CLAHE(clipLimit 2.0, tileGrid 8×8)를 적용합니다.
A5 대상자 검출·ID 고정·ROI: 검출 신뢰도 0.5 이상, 최소 박스 면적 화면의 5% 이상인 사람만 남기고, 이전 박스와 IoU 0.3 이상인 사람을 유지하며 5초간 미검출 시 재선택합니다. 검출 박스 기준 상하좌우 15~20% 여백으로 ROI를 크롭합니다.
A6 얼굴 비식별화: 반드시 포즈 추정 이후에 적용합니다. 얼굴을 먼저 가리면 머리·목 키포인트 정확도가 떨어지기 때문입니다.

3. B 키포인트 단계
포즈 추정 모델이 키포인트 (x, y, confidence)를 출력합니다.
B1 신뢰도 필터링: 신뢰도 0.3 미만이면 결측 처리합니다(MediaPipe visibility는 0.5).
B2 상시 가림 관절 마스킹: 책상 착석 시 무릎·발목 등 하체 관절을 입력에서 제외합니다.
B3 짧은 결측 보간: 실시간은 연속 결측 0.5초까지 마지막 값을 유지하고, 오프라인 학습 데이터는 선형 보간합니다. 초과 시 해당 구간 판정을 보류합니다. 선형 보간은 미래 프레임이 필요해 지연이 생기므로 실시간에서는 쓰지 않습니다.
B4 위치·스케일 정규화: 원점은 어깨 중점, 스케일은 어깨 너비(정면 설치) 또는 귀-어깨 거리(측면 설치)입니다. 스케일은 바른 자세일 때만 갱신합니다. 거북목에서는 귀-어깨 거리 자체가 변해, 계속 갱신하면 그 변화가 정규화로 지워지기 때문입니다.

4. C 시계열 단계
C1 One Euro Filter 평활화: min_cutoff 1.0, beta 0.007, d_cutoff 1.0이며, 떨림이 심하면 min_cutoff 0.5, 1초 이내 반응이 필요하면 beta 0.02~0.05로 조정합니다. B4 정규화보다 먼저 적용합니다. beta 0.007은 픽셀 좌표 기준 값이라 정규화 좌표(1 내외)에서는 필터가 거의 반응하지 않기 때문입니다.
C2 자세 특징 계산: 목 각도, 어깨 기울기 등을 계산합니다. 좌우 기울기는 두 점이 충분히 떨어질 때만 계산해, 측면 설치에서 겹친 어깨·귀의 노이즈 값을 자동 제외합니다(FEATURE_VALIDITY).
C3 개인 기준선·드리프트 재보정: 시작 시 바른 자세 10초의 중앙값을 기준선으로 등록합니다. 평균 대신 중앙값을 써서 캘리브레이션 중 잠깐 움직여도 기준선이 흔들리지 않습니다. 장시간 사용 시 '바른 자세' 판정 구간에서만 기준선을 EMA(α 0.001)로 갱신합니다.
C4 슬라이딩 윈도우·히스테리시스: 윈도우 3초, 스트라이드 1초이며, 윈도우의 70% 이상이 불량이면 불량 진입, 30% 이하면 해제합니다. 불량 상태가 정해진 시간 이상 지속되면 알림을 보냅니다.

5. D 학습 데이터 단계 (오프라인)
D1 라벨 정제: 자세 전환 경계 앞뒤 0.5초는 학습에서 제외하고, 라벨러 2인 이상이 작업해 Cohen's kappa 0.7 미만 구간은 재검토합니다.
D2 사용자 단위 분할: Leave-One-Subject-Out 또는 GroupKFold로 나누며, 반드시 증강 전에 분할해 같은 사람의 증강본이 학습·검증에 섞이는 데이터 누수를 막습니다.
D3 데이터 증강: 회전 ±10°, 스케일 0.9~1.1, 좌표 지터 0.01, 관절 드롭아웃 10%를 적용합니다. 좌우 반전 시 좌/우 관절 인덱스와 방향 라벨을 함께 교환합니다. 회전·스케일·반전은 세션 전체에 같은 값을 적용합니다. 회전 10°가 목 각도 임계값과 같아 프레임마다 바꾸면 라벨 의미가 깨지기 때문입니다. 영상 입력 모델이면 밝기 ±30%, 대비 ±20% 증강도 씁니다.
D4 클래스 불균형 처리: 바른 자세 데이터가 대부분이므로 빈도의 역수를 클래스 가중치로 쓰거나 Focal Loss(γ 2)를 씁니다.

6. 구현하며 바뀐 점
판정 규칙(RULES)은 임시 기준이며, 라벨 기준이 확정되면 임계값을 조정하거나 학습 모델(PosturePipeline(classifier=...))로 교체합니다. 그 밖에 C1을 B4보다 앞에 둔 것, 실시간 결측은 마지막 값 유지, 기준선은 중앙값, 스케일은 바른 자세일 때만 갱신, 증강은 세션 단위로 동일 적용한 것이 구현 과정에서 바뀌었습니다.

7. 후처리 6단계 개요
전처리·판정까지는 "지금 자세가 흐트러졌는가"만 답합니다. 후처리는 그 판정을 사용자에게 언제, 어떻게 알릴지와 기록을 어떻게 정리·평가할지를 담당합니다.

E1 자리 비움 처리: 사람이 5초 이상 안 보이면 상태를 초기화하고(absent_reset_sec 5), 10분 이상 비웠다 돌아오면 재캘리브레이션합니다(recalibrate_after_absent_sec 600). 구부정하게 있다가 자리를 떠도 '불량' 상태가 유지되어 빈자리에 알림이 울리는 것을 막습니다.

E2 자세 유형 판별: 불량 구간 동안 기준을 넘은 특징을 누적해 가장 많은 유형을 이유로 표시합니다(REASON_NAMES). "자세가 나빠요"보다 "거북목 자세가 30초째예요"가 교정에 도움이 됩니다.

E3 알림 정책: 지속 시간 조건, 재알림 간격 300초, 쿨다운 60초, 시간당 상한 6회, 알림 2회 후 단계적 강도 상승(escalate_after_alerts 2)을 둡니다. 알림이 너무 잦으면 사용자가 로봇을 꺼버리는 알림 피로를 막기 위해서입니다.

E4 구간 정리: 3초 이하로 끊긴 같은 상태는 병합하고(merge_gap_sec 3), 5초 미만 구간은 흡수합니다(min_segment_sec 5). 리포트와 평가에서 구간 수가 노이즈로 부풀지 않게 합니다.

E5 세션 리포트: 바른 자세 비율, 불량 구간 수·최장 시간, 유형별 시간, 알림 횟수, 10분 단위 추이를 정리합니다(session_report(block_sec=600)). 사용자 피드백과 장기 추적에 쓰입니다.

E6 성능 평가: 프레임 단위 정밀도·재현율·F1, 구간 단위 감지율, 시간당 오알림, 알림 지연을 계산합니다(event_min_overlap 0.3). RULES·HYSTERESIS 임계값을 숫자로 비교하며 조정하기 위해 필요합니다.

8. 임계값 조정 팁
evaluate() 결과에서 시간당 오알림(false_alerts_per_hour)과 구간 감지율(event_recall)을 함께 보세요. 프레임 단위 F1이 높아도 오알림이 잦으면 실사용에서는 실패입니다.
