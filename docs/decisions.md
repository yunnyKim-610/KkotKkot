# 결정 기록

결정을 바꿀 때는 이 표를 먼저 고치고, 관련 코드·문서를 함께 수정한다.

| # | 주제 | 결정 | 이유 | 상태 |
| --- | --- | --- | --- | --- |
| 1 | 제품 형태 | 기존 서비스 로봇(공장 물류 로봇, 사무실 배송 로봇)에 붙이는 센싱 모듈 + 근로자 UWB 태그 | 감시 장치처럼 보이지 않게, 이미 일하는 로봇에 도움 기능을 더함 | 확정 |
| 2 | 사람 식별 | 얼굴 인식 없음. UWB 태그 방향·거리와 영상 속 사람 위치를 매칭 | 개인정보 부담 최소화, 태그 착용 = 참여 동의 | 확정 |
| 3 | 알림 | 본인 태그 진동 (앱 알림 보조) | 동료 앞에서 지적받는 느낌 방지 | 확정 |
| 4 | 메인 모델 | YOLO11s-pose (COCO-17) | 원스테이지, 1~5명 근거리에 충분, 학습 도구 간편 | 확정, 라이선스 미결 (#11) |
| 5 | 3D 복원 | 스테레오 깊이 카메라 + IMU 중력 보정, 결측 관절만 리프팅 TCN | 시점에 따른 2D 각도 왜곡 제거 | 확정 |
| 6 | 자세 판정 | 1차 규칙(REBA/RULA, 사무실은 개인 기준선) → 2차 경량 TCN | 학습 데이터 없이 시작 가능, 설명 가능 | 확정 |
| 7 | 추론 엔진 | ONNX Runtime + TensorRT 실행 공급자 | Jetson GPU 활용, 모델 형식 단일화, 연산 자동 대체 | 확정 |
| 8 | SBC | Jetson Orin NX 16GB (사무용 보급형은 Orin Nano 8GB 검토) | 메모리 여유, 같은 크기·소프트웨어 | 확정 |
| 9 | 보조 MCU | **ESP32-S3** (이전 검토안 STM32G4에서 변경) | 개발 편의·비용, 팀 경험 | 확정, 주의사항은 CLAUDE.md |
| 10 | UWB | 로봇·태그 모두 Qorvo DW3000 계열, 태그는 DWM3001C 모듈 | 제조사 간 호환 문제 회피, 인증 모듈 | 확정 |
| 11 | YOLO 라이선스 | Ultralytics 기업 라이선스 구매 또는 RTMPose/RTMO(Apache 2.0) 전환 | AGPL-3.0 상용 배포 문제 | **미결** |
| 12 | 소프트웨어 구조 | Docker 컨테이너 5개 + Compose, vision 네트워크 차단 | 영상 격리, 장애 격리, 버전 고정 | 확정 |
| 13 | 통계 저장 | Supabase(Postgres) zone_stats, 기기는 Edge Function으로만 쓰기 | 기존 저장소의 Supabase 재사용, 기기에 관리자 키 미보관 | 확정 |
| 14 | CI | GitHub Actions: ruff + pytest, firmware 변경 시 ESP-IDF 빌드 | 회귀 방지 | 확정 |
| 15 | PRD 방향 정리 | PRD/PRD.md 와 code/DB-main/docs 의 일부는 천장 카메라 + 경광등 버전. 로봇 모듈 기준으로 갱신 필요 | 두 방향이 섞여 있음 | **미결** |
